Design Manual

Colour Scheme

Each Gallery sets three colour scales through top-level theme in site.md: a neutral surface scale, a brand scale, and a gradient-end scale, for example neutral: stone, brand: amber, gradient: yellow. Each scale can use a Tailwind name or a map of custom colour stops. If the theme is not set, it uses standard Tailwind Slate, Orange, and Red. Invalid themes stop the build. Named scales use the standard colours from Tailwind CSS colours with semantic tokens. Main, sidebar, agenda, filter, and editing surfaces use the active theme. The sidebar uses adjacent palette stops, darker than the main surface in light mode and lighter in dark mode.

Custom colours use quoted #RRGGBB or oklch(L% C H) values. Neutral needs stops 50, 100, 200, 400, 500, 600, 800, 900, and 950; brand needs 300, 400, and 700; gradient needs 400 and 700. Check text contrast in both light and dark modes. Restart the dev server after changing a theme. See docs/reference/GALLERY-THEMES.md for complete examples and migration steps.

Brand and gradient colours come from the active theme. Red remains reserved for destructive actions and error states outside the default brand gradient. Info, success, and warning states use named status tokens. Photo, lightbox, editor, and debug overlays may use fixed dark colours when their backdrop is explicitly dark. Token definitions live in src/app.css.

Font Stacks

The project currently uses the default Tailwind CSS font stacks, as no custom fonts are defined in either tailwind.config.ts or src/app.css.

  • Sans-serif: 'ui-sans-serif', 'system-ui', '-apple-system', 'BlinkMacSystemFont', "Segoe UI", 'Roboto', "Helvetica Neue", 'Arial', "Noto Sans", 'sans-serif', "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol", "Noto Color Emoji"
  • Serif: 'ui-serif', 'Georgia', 'Cambria', "Times New Roman", 'Times', 'serif'
  • Monospace: 'ui-monospace', 'SFMono-Regular', 'Menlo', 'Monaco', 'Consolas', "Liberation Mono", "Courier New", 'monospace'
